# Data Directory

This public repository includes only small mapping and audit files.

The raw Dubai Police traffic incident CSV is not included. Download it from:

[https://data.dubai/en/l/469979](https://data.dubai/en/l/469979)

Place the downloaded CSV at the repository root as:

`traffic_incidents_2026-06-01_10-44-37_1.csv`

Generated full-size datasets are intentionally ignored:

- `data/processed/traffic_incidents_cleaned.csv`
- `data/processed/traffic_incidents_eda_ready.csv`
- `data/processed/incident_points_h3_res8.csv`
- `data/processed/grid_time_incident_counts_res8_3h.csv`
- `data/processed/grid_time_model_sample_res8_3h.csv`
- `data/dashboard/`
